# TKP Roadmap

## v0.1.0 — Foundation MVP

Repositorio manual usable como fuente de verdad.

## v0.2.0 — CLI Básica

Automatización mínima para crear decisiones, sesiones y handoffs.

## v0.3.0 — Indexer

Índices automáticos por decisión, sesión y proyecto.

## v0.4.0 — Search

Búsqueda local por archivos y metadata.

## v0.5.0 — AI Context Builder

Generador de contexto mínimo para agentes.

## v0.6.0 — Handoff Engine

Handoffs generados y validados automáticamente.

## v0.7.0 — Dashboard

Panel visual del estado de TKP.

## v0.8.0 — Memory Bus

Sistema coordinado para múltiples agentes.

## v0.9.0 — Semantic Layer

Búsqueda semántica, embeddings y RAG.

## v1.0.0 — Stable Protocol

Versión estable para operación real del ecosistema TORO.
