# TKP Sprint Plan

## Sprint 1 — Foundation MVP

Crear estructura, templates y documentación base.

Estado: En curso / v0.1.0

## Sprint 2 — CLI Básica

Comandos para crear sesiones, decisiones y handoffs.

Comandos objetivo:

```bash
tkp new-session
tkp new-decision
tkp handoff
tkp current
tkp doctor
```

## Sprint 3 — Indexer

Generar índices automáticos de decisiones, sesiones y proyectos.

## Sprint 4 — Search

Búsqueda local por palabra clave y metadata.

## Sprint 5 — AI Context Builder

Generar contexto mínimo para cada agente.

## Sprint 6 — Handoff Engine

Automatizar handoffs entre agentes.

## Sprint 7 — Dashboard

Panel visual del estado del ecosistema.

## Sprint 8 — Memory Bus

Sistema coordinado para múltiples agentes.

## Sprint 9 — Semantic Search

Embeddings, RAG y búsqueda semántica.

## Sprint 10 — v1.0

Versión estable documentada.
