# Principles

## 1. Fuente de verdad antes que memoria dispersa

TKP prioriza documentos vigentes sobre conversaciones largas.

## 2. Protocolo antes que magia

No se asume memoria compartida entre agentes. Se diseña coordinación explícita.

## 3. Cada sprint deja algo funcionando

Nada de trabajo preparatorio sin entrega usable.

## 4. Simplicidad inicial

Markdown y Git antes que dashboards, bases de datos o embeddings.

## 5. Trazabilidad

Toda decisión relevante debe poder rastrearse.

## 6. Contexto mínimo suficiente

Un agente debe recibir solo el contexto necesario para actuar bien.

## 7. No complacencia operativa

El sistema debe señalar contradicciones, ambigüedades y decisiones pendientes.
