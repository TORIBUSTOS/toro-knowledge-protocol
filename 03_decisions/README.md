# Decisions

Este directorio contiene el registro de decisiones del ecosistema TKP/TORO.

## Convención de nombres

```txt
DEC-001-nombre-breve.md
DEC-002-nombre-breve.md
```

## Estados posibles

- Propuesta
- Aprobada
- Reemplazada
- Archivada

## Regla

Una decisión aprobada prevalece sobre sesiones históricas o notas sueltas.
